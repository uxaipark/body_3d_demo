# SOMA Public Demo

공개 시연용 독립 소스 프로젝트입니다. 홈, 전신 디지털 트윈, 수면무호흡 및 광학 링 시뮬레이터를 제공합니다. 한국어·영어와 공통 성능 모드를 지원합니다.

손목 센싱 전용 페이지·소스·정적 파일, 연구 기록, 사용 매뉴얼 및 문서 다운로드, 제작자 소개를 제외했습니다. 전신 모델의 일반적인 손·손목 해부학과 피부 단면 기능은 유지합니다. 기존 사이트의 Git 이력, 배포 식별자 및 로컬 환경 파일은 포함하지 않습니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 3011
```

브라우저에서 http://localhost:3011 을 엽니다.

## 생산 빌드와 검증

```sh
npm test
npm run build
npm start -- --port 3011
```

빌드 시 공개 범위 검사가 자동 실행됩니다. 배포 산출물은 `dist/client`와 `dist/server`입니다. Cloudflare Workers 호환 빌드이며, 별도 호스팅 계정과 배포 설정을 사용해야 합니다. 기존 SOMA 사이트에는 연결되어 있지 않습니다.

해부학 계산 소스를 변경한 경우 `npm run build:body-assets`로 모델을 재생성합니다. 이 명령은 Chrome이 필요하며 `CHROME_PATH`로 경로를 지정할 수 있습니다.

## 포함 범위 및 출처

공개 경로: `/`, `/simulators/body`, `/simulators/sleep`, `/simulators/ring`.

해부학 및 모션 자산의 출처와 라이선스 고지는 `public/models/ATTRIBUTION.md`, `public/motions/ATTRIBUTION.md`에 유지했습니다. 제작자 소개 제거는 제3자 자산의 출처 고지를 제거하는 의미가 아닙니다. 자산 재배포에는 각 고지의 조건이 적용됩니다.

신호는 가상 실험용 합성 데이터이며 임상 검증된 진단 결과가 아닙니다.

## 공개본 검증 결과

타입 검사, 생산 빌드, 19개 테스트 및 한국어·영어 데스크톱/모바일 브라우저 검증을 통과했습니다. 제외한 페이지·정적 문서 URL의 404 응답을 확인했습니다. `node scripts/public-browser-check.mjs`로 실행 중인 로컬 서버를 재검증할 수 있습니다.

전신 피부 단면은 공개용 공통 조직 변형 모델을 사용하며 손목 전용 조직 전달 함수와 센싱 모듈에는 의존하지 않습니다. 일반 3D 회전 입력 처리는 독립 공통 모듈로 분리했습니다.

## 광학 링 공개 데모

기존 손·손목 해부학 메시에서 검지 근위부 피부 교차점을 이용해 링을 구성합니다. 피부 투명도, 링 확대, 착용/미착용, 뒤척임, 합성 PPG Red/IR 및 ACC XYZ와 CSV를 제공합니다. 맥박·SpO₂는 사용자가 입력한 시뮬레이션 기준값이며 임상 검증된 추정 결과가 아닙니다. EEG/EOG/턱 EMG, 수면 단계, AHI를 제공하지 않으며 완전한 PSG를 대체하지 않습니다. 12채널 패치, 정전용량 배열, 빔포밍 및 혈압 추정 모듈은 포함하지 않습니다.
